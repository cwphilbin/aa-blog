# Repository instructions

Every task must read CONTENT_STANDARD.md first. Never change or violate any rule in it unless the prompt explicitly names that rule and says to change it. Change only what the prompt asks; everything else stays exactly the same.

Standing user exception: for admin-only or tracking-only changes, run targeted checks and a tracking-only asset build; do not run the full monthly content baseline gate. Preserve existing report content and layout. Commit and push before deploying. Changes to report content, rendering, layout, or email content still follow CONTENT_STANDARD.md.
